# Project Knowledge Base

This directory holds durable project knowledge that should survive individual tasks and chat sessions.

Use it for:

- resolutions of difficult problems,
- development policies and guardrails,
- UI and UX design guidance,
- architecture and implementation conventions,
- reusable troubleshooting notes.

## Structure

- `governance/` — policies, team rules, workflow guidance
- `development/` — coding, validation, implementation guidance, and test gotchas
- `ui/` — UI/UX guidelines and reusable interaction guidance
- `resolved-problems/` — durable writeups of important solved issues and their preferred fixes

## Usage policy

- Prefer adding durable guidance here when the information is likely to help future tasks.
- Keep this knowledge base project-specific.
- Put transient debugging notes elsewhere; promote them here only after they become reusable guidance or policy.
- When a document here becomes normative, reference it from `AGENTS.md` or other governing artifacts.
