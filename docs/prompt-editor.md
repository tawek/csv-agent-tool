# Problem

The user wants to edit the prompt template text but there UI is cluttered with the preview and the editor as well as the table view for the columns.

# Solution

Add a "maximize" button to the prompt editor that maximizes the editor and the table view to fill the entire window.

This basically collapses the csv data panel and the preview panel.

If you click the maximize button again, the panel will be restored to its original size - all the panels will be visible again.

This is purely cosmetic and does not affect the functionality of the application except for the user experience.

Make the button unobtrusive and have some "maximize" icon instead of a text label.
